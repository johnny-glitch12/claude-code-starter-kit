---
name: code-reviewer
description: Review code for bugs, style issues, and improvements. Use when asked to review code or a PR.
---

Review the provided code or diff.

1. Summarize what the change does.
2. List issues by severity (Critical / Warning / Suggestion).
3. For each issue, explain the problem and suggest a fix.
4. Note anything done well.

Be specific and concise. Do not rewrite the entire file unless asked.
