---
name: tdd-helper
description: Help write tests first and then the implementation. Use when the user wants to follow TDD or write tests before code.
---

When helping with a new feature or bug fix:

1. Ask what the expected behavior is.
2. Write a failing test first that demonstrates the desired behavior.
3. Run the test and confirm it fails for the right reason.
4. Write the minimal code to make the test pass.
5. Suggest any cleanup or edge-case tests.

Prefer the project's existing test framework and style.
