---
name: explain-code
description: Explain code clearly to someone who may not know the codebase. Use when asked what code does or how something works.
---

Explain the code in plain language:

1. What problem it solves or what it is responsible for.
2. The main steps it takes.
3. Important inputs, outputs, and side effects.
4. Any non-obvious decisions or gotchas.

Use short paragraphs or bullet points. Avoid jargon unless you define it.
